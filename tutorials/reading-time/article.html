A small WordPress plugin is a good way to learn how hooks turn an idea into a feature. In this tutorial, you will build a plugin that adds an estimated reading time above a blog post, without editing your theme or changing the saved article.

You will finish with an installable plugin, understand every part of its PHP file, and check its behaviour on a real post. Basic familiarity with PHP variables and functions will help. Allow about 30–45 minutes on a local or staging WordPress site.

1. Decide what the plugin should do

Our rule is simple: count the words in the rendered post text, divide by 200, then round up to a whole minute. A 450-word article becomes “3 minutes read.” The reading speed is a configurable assumption in the code, not a measurement of your reader.

  • Show the estimate on individual blog posts in the main content area.
  • Leave pages, archives, feeds, the dashboard, REST responses, and password-protected content alone.
  • Show no label when there is no readable text.
  • Keep the original post content and add the label only when WordPress renders it.

This is a deliberately small text estimate. It does not account for diagrams, video, reading code, or language-specific reading speeds. The word matcher groups letters and numbers, including accented words and internal apostrophes or hyphens. It is not a word segmenter for languages such as Chinese or Japanese; adapt the counting rule before using it for those articles.

3. Create the plugin folder

Use a local WordPress installation or a staging copy where you can access the files and the administrator dashboard. This example requires WordPress 6.6 or later and PHP 8.0 or later. You need permission to install plugins; managed plans may restrict that permission.

Inside wp-content/plugins, create a folder called notebook-reading-time. Inside that folder, create a plain-text file named notebook-reading-time.php. Make sure your editor has not added a hidden .txt extension.

The folder keeps this feature separate from the theme. Changing themes will not remove the plugin, though the position of the post-content block determines where the label appears.

4. Add the complete PHP file

Paste this entire file into notebook-reading-time.php and save it as UTF-8. Include the opening <?php once. Do not paste it into a post, a Custom HTML block, or your theme’s functions.php.

Download the complete plugin ZIP if you want to compare your file with the working example. The ZIP contains the same PHP shown above.

5. Understand how the pieces fit together

The plugin header tells WordPress the name, version, and runtime requirements. The ABSPATH guard prevents the file from doing anything when requested directly outside WordPress. Prefixing function names with knr_ reduces the chance of colliding with another plugin.

knr_word_count() receives rendered HTML. It separates adjacent tags so neighbouring paragraphs do not merge, removes markup and script/style contents with wp_strip_all_tags(), and decodes entities such as &nbsp;. The Unicode regular expression counts word-like groups instead of punctuation. A failed match returns zero.

knr_minutes() keeps the arithmetic separate from WordPress. The max() call prevents a negative count, division converts words into minutes, and ceil() rounds up. Change $words_per_minute = 200; to another positive integer if your content needs a different estimate. Never use zero, because division by zero fails.

knr_add_reading_time() first checks the context. WordPress can ask for content more than once, including inside secondary queries. The main-query and loop checks keep the label attached to the main blog post. The other guards exclude contexts where the extra label would be surprising.

Next, the function calculates the minutes. If the count is zero it returns the content unchanged. Otherwise, _n() selects the singular or plural phrase, number_format_i18n() formats the number, and esc_html() escapes the final label before placing it inside a paragraph.

Finally, add_filter() connects the function to the_content at priority 20. WordPress’s normal block and shortcode processing has generally run by then. Your callback receives a string and must return a string. Printing with echo here can put output in the wrong place. We also avoid calling the_content() inside its own filter, which would recurse.

6. Install and check a real post

  • If you created the folder in your local site, open Plugins → Installed Plugins and activate Notebook Reading Time.
  • If you downloaded the ZIP, open Plugins → Add New Plugin → Upload Plugin, choose the ZIP, install it, and activate it. Menu wording can vary with the WordPress version.
  • Create a test blog post with ordinary paragraph text. Publish it only on your local or staging site, then use its public single-post URL.
  • Look immediately above the post content for the estimate. A theme may have its own reading-time label; disable one of them if you see a duplicate.
  • Open an ordinary Page and the blog archive. This plugin should not add a label there.

The estimate belongs above the post body, not necessarily above the title or featured image. In a block theme, ensure the single-post template includes the Post Content block. A page builder or template that bypasses the normal content filter may require its own integration.

7. Test the edges

Use plain repeated words for exact checks so headings and captions do not add unexpected words. For example, 200 repetitions of “hello” should produce one minute; 201 should produce two. The calculator above lets you check the expected arithmetic first.

  • 0 words: no label. An image-only post is outside this text estimate.
  • 1 or 200 words: “1 minute read.”
  • 201 or 400 words: “2 minutes read.”
  • 401 words: “3 minutes read.”
  • HTML and entities: tags should not count as words, and “hello&nbsp;world” should count as two.
  • Deactivate the plugin: the label should disappear while the original post text remains.

Rendered shortcode output, captions, and code text can contribute to the count. If another plugin inserts text before this filter, that text can also be counted. For a larger product, define a content policy for those cases and test it before promising an exact estimate.

8. Troubleshoot and customise

The plugin does not appear: check the folder structure and the Plugin Name header. The file must end in .php, and a ZIP upload must contain the plugin folder with the PHP file inside it.

Activation reports a PHP error: compare your file with the complete example, check for a duplicated opening PHP tag, and confirm PHP 8.0 or later. If an edit prevents the site from loading, rename the plugin folder through your local file manager or hosting file manager to disable it, then repair the file.

No label appears: verify that this is a blog Post, the plugin is active, the post is not password protected, and the theme renders its main content normally. If you use a page cache, clear the affected post after activating or changing the plugin, then visit the public URL again.

Change the appearance: add the following CSS through the site’s custom CSS facility or your child theme stylesheet. The paragraph inherits your theme’s colours and remains readable in light and dark themes.

Remove the feature: deactivate and delete Notebook Reading Time from the Plugins screen. It creates no database tables, options, or post metadata, so the tutorial plugin has no stored settings to clean up.

9. Your next exercise

Change the reading speed to 250 words per minute, then predict the result for 500 and 501 words before checking it. You should get two minutes and three minutes. Keep the counting function and calculation separate as you experiment; that makes each rule easier to test.

For a more advanced version, add an administrator setting with input validation and a positive minimum value, or create a dynamic block so an editor can choose where the estimate appears. Those are separate features; the plugin you built here is already complete for the single-post text estimate.
